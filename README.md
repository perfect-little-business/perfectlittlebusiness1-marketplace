# Perfect Little Business Marketplace

The Claude plugin marketplace for Perfect Little Business™.

This marketplace hosts the AI Operating Layer™: the infrastructure that turns AI from a tool into an operating system for entrepreneurs who are subject matter experts.

## Available Plugins

### perfectlittlebusiness (v1.5.1)

Your AI Operating System (AIOS), installed in one move, and your way into Perfect Little Business HQ from Claude, Claude Code or Codex. Run your ten planning steps here or in HQ, and each one saves to your business plan in HQ and to your `brain/` folder. Twenty-seven skills in all, plus three protective hooks.

## Installation

### In Claude (Cowork)

1. Open **Customize**, then **Personal plugins**.
2. Click **+**, then **Add marketplace**, then **Sync a marketplace from a GitHub repository**.
3. Paste `perfect-little-business/perfectlittlebusiness1-marketplace`.
4. Install the **perfectlittlebusiness** plugin. Its connection to Perfect Little Business HQ and all its skills install with it.

### In Claude Code

```
/plugin marketplace add perfect-little-business/perfectlittlebusiness1-marketplace
/plugin install perfectlittlebusiness@plb1
```

### In Codex

```
codex plugin marketplace add perfect-little-business/perfectlittlebusiness1-marketplace
codex plugin add perfectlittlebusiness@plb1
```

### Then, in any project folder

Run `/setup` (or `/perfectlittlebusiness:setup` in Claude Code). The first time a step reads or saves your plan, sign in with the email of your Perfect Little Business HQ account. If you already have a plan in HQ, `/setup` brings it into your `brain/` folder.

Command names are bare in Cowork (`/start`) and start with the plugin's name in Claude Code (`/perfectlittlebusiness:start`).
